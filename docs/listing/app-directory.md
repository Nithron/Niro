## Short description

Security-first moderation: stops scam links, hacked-account spam and raids, with cases, logs, role panels, welcome messages and tickets. Set up from a web dashboard.

## Description

**Niro keeps your community safe without getting in the way.**

**Guardian** catches what moderators can't watch for all day:
- scam and phishing links, including look-alike domains;
- hacked accounts that spam the same message across channels. They are quarantined at once, so your staff can decide;
- raids. Niro switches on raid mode, pauses invites and sums up the joins.

**Moderation** with clear records:
- Warn, timeout, kick and ban, each with a numbered case and a reason.
- Temporary bans lift themselves.
- Ready-made AutoMod rules.

**A server log** that shows edits, deletes, joins, role changes and moderation actions, with who did them.

**Community tools:** role panels (buttons or menus), welcome and goodbye messages, and support tickets with private threads and transcripts.

**Built for trust:**
- Least-privilege permissions; never Administrator.
- No pings beyond what each message needs.
- Message text isn't stored, except ticket transcripts, which expire.
- The code is open for review on GitHub.

Configure everything at niro.nithron.com.
