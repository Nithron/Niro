# Niro user guide

Niro is a Discord bot by Nithron that puts security first. It handles moderation, protects your server against hacked accounts, scam links and raids, logs what happens, and gives you role panels, welcome messages and support tickets. You set everything up from a web dashboard, and changes apply in Discord right away.

Niro never asks for the Administrator permission, and it keeps as little data as it can. Message text is not stored in its database, except in ticket transcripts.

- Hosted dashboard: https://niro.nithron.com
- Running your own copy instead: [self-host guide](../self-host.md)

## Modules

Niro is split into modules. You turn each one on or off per server on the dashboard's **Modules** tab.

| Module | On by default |
|---|---|
| Core (`/ping`, `/about`, `/modules`) | Always on |
| Moderation | Yes |
| Guardian | Yes |
| Logging | No |
| Role panels | No |
| Welcome | No |
| Tickets | No |
